# Common Patterns

Standard `ApiResponse<T>` envelope (`{success, data?, error?, meta?}`), repository pattern for data access, and reusable hooks (e.g. `useDebounce`) are covered in the `backend-patterns` / `frontend-patterns` / `coding-standards` skills — reference those rather than re-deriving conventions per project.

## Skeleton Projects
When starting new functionality, look for a battle-tested skeleton/starter first. Evaluate candidates in parallel (security, extensibility, relevance) rather than serially, then build inside the proven structure instead of from a blank file.
