# /learn — Extract Reusable Patterns

Run mid-session after solving something non-trivial, to save it as a skill.

Extract: error-resolution patterns (error → root cause → fix), non-obvious debugging techniques, library/API workarounds, discovered project conventions.

Skip: typos, one-off fixes, one-time external outages.

1. Identify the most valuable reusable insight from this session.
2. Draft `~/.claude/skills/learned/<pattern-name>.md`:
```markdown
# <Pattern Name>
**Context:** when this applies
## Problem
## Solution
## Example
## When to Use
```
3. Confirm with the user before saving.
